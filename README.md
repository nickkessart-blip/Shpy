# SHPY — Prototype 0.1

Модульный 2D-прототип шпионской инкременталки на Phaser 4 + TypeScript + Vite.

## Документы
- [GAME_BIBLE](docs/GAME_BIBLE.md) — канон игры.
- [GAME_DESIGN](docs/GAME_DESIGN.md) — цикл, миссии и прогрессия.
- [TECHNICAL_ARCHITECTURE](docs/TECHNICAL_ARCHITECTURE.md) — архитектура и платформы.
- [COMBAT_SPEC](docs/COMBAT_SPEC.md) — стрельба, враги и укрытия.
- [MVP_SCOPE](docs/MVP_SCOPE.md) — объём и критерии MVP.
- [ROADMAP](docs/ROADMAP.md) — этапы производства.
- [DECISIONS](docs/DECISIONS.md) — журнал решений.

## Запуск
Требуется Node.js 26 LTS и npm:
```bash
npm install
npm run dev
```
Откройте адрес Vite, по умолчанию http://localhost:5173.

## Проверки
```bash
npm run typecheck
npm run test
npm run lint
npm run build
```

## Управление
- Навести курсор — прицел.
- ЛКМ — выстрел.
- R — перезарядка.
- Esc — пауза.
- Android: «Касание» — тап сразу стреляет, перетаскивание пальца по игровому полю непрерывно двигает прицел; стик и отдельная кнопка огня скрыты. «Виртуальный джойстик» — левый стик двигает прицел, отдельная правая кнопка удерживает огонь; чувствительность 0.5×–4×. В обоих режимах доступны перезарядка, смена оружия и предметы. У оружия разные режимы стрельбы, разброс, отдача и характеристики.

## Настройки, звук и визуальный отклик
Экран настроек доступен из стартового меню, штаба и паузы миссии. Параметры сохраняются отдельно от прогресса: качество графики, музыка, эффекты, схема управления Android, чувствительность прицела, вибрация, параллакс и тряска камеры. Локальные аудиофайлы CC0 перечислены в `src/assets/audio/LICENSES.md`; вибрация зависит от поддержки браузера/устройства.

Исходный код и оригинальные игровые материалы являются собственностью владельца проекта; отсутствие открытой лицензии не выдаёт разрешение на копирование или повторную публикацию. См. [COPYRIGHT.md](COPYRIGHT.md). Сторонние материалы сохраняют свои лицензии, указанные рядом с ними. Публичный репозиторий всё ещё содержит исходники: отключение source maps защищает только собранный web-бандл и не скрывает `main`. GitHub Pages сейчас публикует игру из публичного репозитория. Для приватной разработки нужен отдельный private source-репозиторий и отдельный public deployment-репозиторий, в котором лежит только собранный билд.

## Игровой срез
Штаб → карта сюжетных операций → казино → результаты → штаб. Оружейный шкаф: арсенал, перки, модификации и косметика. Компьютер: улучшения за доллары и отдельный отдел агентов. Враги: охранник, бронированный, штурмовик. Есть HP, магазин/резерв, попадания в голову и тело, укрытия, телеграф атак, доллары, account XP, шесть веток улучшений, агенты с отдельными операциями, комплектующие и локальное сохранение.

## Автоподхват ассетов
Кладите файлы в `src/assets/` по таблице в [src/assets/README.md](src/assets/README.md). Vite обнаруживает их через `import.meta.glob` при запуске dev-сервера и сборке. Если слот пуст, используется геометрическая заглушка.
Примеры:
- `src/assets/backgrounds/casino-main.webp`
- `src/assets/backgrounds/casino-bar.webp`
- `src/assets/enemies/guard.png`
- `src/assets/enemies/armored.png`
- `src/assets/enemies/assault.png`
- `src/assets/props/cover-crate.png`
- `src/assets/weapons/pistol.png`
- `src/assets/ui/logo.png`

## Статус платформ
Исходный код Web-прототипа загружен. GitHub Actions проверяет TypeScript, тесты, линтер и production build; до успешного прохождения CI не считать сборку проверенной. После успешного CI на push в `main` workflow публикует готовую Web-сборку в ветку `prototype-build`. ZIP этой ветки можно получить по адресу https://github.com/nickkessart-blip/Shpy/archive/refs/heads/prototype-build.zip. Для локального запуска распакуйте архив и выполните `python -m http.server 8000`, затем откройте http://localhost:8000. Ветка содержит production-файлы, а не исходники. Capacitor Android/iOS и Tauri Desktop подключаются отдельным этапом после стабилизации боевого ядра. APK и настольные установщики пока не создавались.
