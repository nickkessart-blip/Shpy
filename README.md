# SHPY

Рабочее название: Shpy / «Шпионская инкременталка»  
Жанр: инкрементальный шпионский шутер с управлением агентством.  
Статус: предпроизводство, проектирование игрового прототипа.

## Документы
- [GAME_BIBLE](docs/GAME_BIBLE.md) — канон, видение, мир и принципы.
- [GAME_DESIGN](docs/GAME_DESIGN.md) — игровой цикл, миссии, прогрессия.
- [TECHNICAL_ARCHITECTURE](docs/TECHNICAL_ARCHITECTURE.md) — стек и архитектура.
- [COMBAT_SPEC](docs/COMBAT_SPEC.md) — стрельба, враги, укрытия.
- [MVP_SCOPE](docs/MVP_SCOPE.md) — границы первого прототипа.
- [ROADMAP](docs/ROADMAP.md) — этапы производства.
- [DECISIONS](docs/DECISIONS.md) — журнал решений и открытых вопросов.

## Ключевые решения
1. Гибрид статичных боевых сцен и кинематографичной последовательности сцен.
2. Внутри сцены камера неподвижна, игрок не перемещается.
3. Игрок может стрелять в любой момент; противники умеют прятаться в укрытиях.
4. Сейчас приоритет — прототип геймплея, визуал заменяется геометрическими заглушками.
5. Проект имеет модульную структуру, это не один HTML-файл.
6. Цели: Web, Android, iOS и Desktop.
7. Базовый стек: Phaser 4 + TypeScript + Vite; Capacitor для mobile; Tauri 2 для desktop. Rust — для нативной оболочки Tauri, не для основной игровой логики.

## Статус достоверности
Документы различают подтверждённые решения, проектные рекомендации, гипотезы баланса и открытые вопросы. Числа из раннего концепта не считаются финальным балансом до плейтеста.
